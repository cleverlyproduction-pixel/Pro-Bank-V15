# ProBank static prototype and wallet sandbox

The existing static page has been adapted into a fictional, clearly labeled sandbox interface. It is for UI exploration only—not a bank, wallet, payment service, or production-ready financial product.

## Run locally

Open `index.html` in a browser, or serve the repository with any static file server. No build step, backend, database, account, or external payment integration is required.

## Sandbox behavior

- Add demo funds, simulate a transfer to a preset sample contact, and try simulated airtime/bill actions.
- The displayed balance and activity exist only in page memory and reset on reload.
- No real user information, phone number, bank details, credentials, or payment instructions are requested or sent.
- Every action is explicitly labeled simulated; it does not initiate a transaction or represent a financial record.

This frontend does not implement authentication, KYC, provider integration, persistent records, or real money movement. Do not connect real customer or financial data. Any future live product needs an appropriately authorized provider, a professionally reviewed backend/security design, and applicable Nigerian legal/compliance review before launch.
